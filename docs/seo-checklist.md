# KUTNITI SEO Checklist

## Site-wide

- Unique title and meta description for every page.
- Canonical URL for every page.
- XML sitemap and robots.txt.
- Article, Organization, Breadcrumb and Author structured data.
- OpenGraph and Twitter card metadata.
- Real About, Contact, Editorial Policy, Correction Policy and Author pages.
- No placeholder/lorem ipsum content.
- Mobile-first responsive design.
- Optimize Core Web Vitals: LCP, INP and CLS.

## Article-level

- Strong headline and deck/subheadline.
- Visible author, date published, date updated and reading time.
- Key takeaways box.
- Internal links to topic hubs and related articles.
- Descriptive image alt text.
- Source/fact box for serious analysis.
- Clear category and tags.

## Topic hubs

- Build dedicated hubs for Nepal Budget, AI Governance, FinTech Security, South Asia, NEPSE and Cybersecurity Nepal.
- Each hub should contain evergreen explainers, latest articles, FAQ, timeline and internal links.
